## Why

The project has no user-facing documentation. Developers who discover this tool have no README to understand what it does, how to use it, or how it works internally. A bilingual documentation set (English + Cantonese) serves both the international Rust community and the local Hong Kong team.

## What Changes

- Add `README.md` (English) — project background, usage examples, CLI reference, smart-group logic explanation, project structure overview
- Add `README-HK.md` (Cantonese/Traditional Chinese) — same content localised for Cantonese speakers

## Capabilities

### New Capabilities

- `project-docs`: Bilingual project documentation covering background, usage, CLI reference, smart-group logic, and project structure

### Modified Capabilities

(none)

## Impact

- Two new files at project root: `README.md`, `README-HK.md`
- No code changes
- No dependency changes
